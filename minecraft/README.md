# AC Worlds: Assassin's Creed, Avatar and premodern technology, in Minecraft

A vanilla **Minecraft Java Edition 1.21+** datapack (no mods) that builds
every Assassin's Creed setting, the Avatar worlds (The Last Airbender, The
Legend of Korra, Seven Havens), and working-principle models of premodern
technology, each with its chat-side explanation drawn from the knowledge base
in `knowledge/`.

Everything is generated by plain Python 3 from the `acworlds/` package, so you
can change any building and regenerate.

## Install (you have Minecraft open: this takes two minutes)

**Fastest: the installer.** Make a world first if you don't have one
(Create New World > Creative > World Type Superflat), then from the repo folder:

```
python minecraft/install.py
```

It finds your `.minecraft` folder, lists your worlds, copies the pack into the
one you pick, and prints the three commands to type. Open the world (or `/reload`)
and it builds itself fifteen seconds after you join. Nothing to install
beyond Python 3, which macOS and most Linux have; on Windows get it from
python.org if `python` is not recognised.

**Option A: a fresh world that builds itself (by hand)**

1. Download or clone this repository; the pack is the folder
   `minecraft/datapack/ac_worlds` (or the zip `minecraft/datapack/ac_worlds.zip`).
2. Minecraft > Singleplayer > Create New World. Pick **Creative** and, under
   World > World Type, **Superflat** (flat ground makes the builds sit right).
3. On the same screen click **More > Data Packs**, press **Open Pack Folder**, copy the
   `ac_worlds` folder (or zip) into it, then move the pack to the *Selected*
   column. Click Done, then **Create New World**.
4. Fifteen seconds after you spawn the pack starts building the entire hub
   (every world, every technology model) in rows north of you, force-loading chunks
   as it goes. Watch the chat: it names each build and its offset. Type
   `/function ac:cancel` within those fifteen seconds if you'd rather place
   things yourself.

**Option B: add it to a world you already have**

1. Pause > Open to LAN is not needed. Put the `ac_worlds` folder in
   `.minecraft/saves/<your world>/datapacks/`.
2. In the world run `/reload`. The auto-build arms itself for this world and
   starts in fifteen seconds; `/function ac:cancel` stops it.
3. Stand where you want something, face north, and run a function, for example:

```
/function ac:index                 list everything
/function ac:egypt/giza            the Giza plateau (318 x 307 blocks)
/function ac:atla/wan_shi_tong_library
/function ac:korra/republic_city
/function ac:tech/aqueduct         a technology model with its explanation
/function ac:egypt/all             a whole world laid out in a row
/function ac:hub_avatar            all Avatar worlds; ac:hub_assassins_creed, ac:hub_tech, ac:hub
```

Builds are relative to your feet: the block you stand on becomes the ground
level of the build and the build extends north (-z) and both sides. Each
function force-loads its chunks, waits two seconds, places the blocks, then
releases the chunks, so very large builds work even at low render distance.
The hub needs roughly 1,100 x 2,000 blocks of flat land; `ac:<world>/all`
needs about 1,000 x 300.

Requires 1.21 or newer (the pack uses the `function` folder name and macro
functions). The pack declares `supported_formats` up to 999 so later versions
load it; if a future version renames blocks you will see "unknown block" errors
in chat for those few commands and the rest still builds.

## What is in it

| Set | Worlds | Landmarks |
|---|---|---|
| Assassin's Creed | Holy Land (AC1), Italy (II/Brotherhood), Constantinople (Revelations), Colonial America (III/Rogue), Caribbean (IV/Freedom Cry/Liberation), Paris (Unity), London (Syndicate), Egypt (Origins), Greece (Odyssey), Viking England and Norway (Valhalla), Baghdad (Mirage), Japan (Shadows), Chronicles (China/India/Russia), Hexe (placeholder) | 63 |
| Avatar | The Last Airbender (10 locations incl. Wan Shi Tong's Library), The Legend of Korra (6), Seven Havens (3, stylised) | 19 |
| Technology | 37 working-principle models, Egypt to the Inca, each linked to a record in `knowledge/` | 37 |

`datapack/INDEX.md` lists every function with its footprint. The Library of
Alexandria is part of `ac:egypt/alexandria`; its spirit-world cousin is
`ac:atla/wan_shi_tong_library`.

## The knowledge base

`knowledge/premodern_technology.json` holds 50+ records (Egypt, Mesopotamia,
Persia, Greece, Rome, China, India, the Islamic world, medieval Europe, the
Americas, Africa, Japan): what it is, how it works, why it matters, where it
appears in the games, which Minecraft functions show it, and sources.
`knowledge/README.md` is the rendered catalogue. In game, every
`/function ac:tech/<model>` prints its record's summary and mechanism.

Your own course notes go in `knowledge/my_notes/` (see the README there);
each file becomes `/function ac:notes/<name>`.

## Regenerate after editing

```
python minecraft/generate.py                       # rebuilds datapack/ and knowledge/README.md
python -m unittest discover -s minecraft/tests     # meshing, command syntax, every build
```

Code map:

- `acworlds/voxel.py` sparse block grid and primitives (fill, dome, pyramid, arch, roofs, trees)
- `acworlds/export.py` greedy meshing into `/fill` commands, datapack writer
- `acworlds/structures.py` reusable architecture (houses, towers, temples, mosques, cathedrals, ships, aqueducts, castles, pagodas...)
- `acworlds/palettes.py` block palettes per tradition
- `acworlds/worlds/*.py` one module per setting; `acworlds/technology.py` the models
- `generate.py` hub layout, chunk-loading sequences, auto-build, index, catalogue

To add a landmark: write a function `def my_place(v: Voxel)` in the world's
module using the primitives (ground at y = 0, build upward from y = 1), then
append `.build(Build("my_place", "My Place", "one line", my_place))` to that
module's `WORLD`. Regenerate.

## Scale and accuracy

Landmarks are roughly 1 block = 2 to 4 metres and simplified to what the
primitives can express; the point is recognisable massing, correct plan, and
walkable interiors where they matter (Khufu's Grand Gallery and King's
Chamber, Derinkuyu's seven levels, the Pantheon's oculus, the buried
library). Hexe and Seven Havens are not released, so those are labelled
placeholders built from what has been announced.
